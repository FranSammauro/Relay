# Relay

Relay es un motor de colas de trabajos distribuido, persistente y
tolerante a fallos, escrito en Rust. El proyecto se documenta en dos
idiomas, con contenido equivalente en ambos:

- [README en español](./README_ES.md)
- [README in English](./README_EN.md)

Relay is a distributed, persistent, fault-tolerant job queue engine
written in Rust. The project is documented in two languages, with
equivalent content in both:
